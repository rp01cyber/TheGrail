# Apply guide — consolidated update

This package folds in several updates at once (edit-conflict protection, Markdown
export, login lockout, a persistent Home button, folder-permission changes, and
the admin-managed tag repository). Because these touch overlapping files and you
weren't sure which earlier updates were applied, the safe path is to **replace
the code folders wholesale** — your data is never in those folders.

## What changed since your deployed version
- **Edit-conflict protection** — a second person saving a page that changed
  under them is warned instead of silently overwriting.
- **Markdown export** — per-page "Download as .md" and Manage → "Export all (.zip)".
- **Login lockout** — 5 failed attempts locks an account until an admin unlocks
  it (Users page → Unlock, or `python manage.py axes_reset`). Adds django-axes.
- **Persistent Home button** — top bar, always visible.
- **Folder permissions** — any logged-in user can *add* a folder under an
  existing one; *renaming, moving, deleting, and top-level creation* are
  admin-only. Page edit/delete unchanged (still the grant system).
- **Tag repository** — admin-managed tag list (Manage → Manage tags), seeded
  with defaults. On a page you pick tags from a searchable list; only admins
  create tags. Tags on a page are clickable to search.
- **Session length** — 1 day (set earlier).

## Apply it (on the Linode)

```bash
sudo systemctl stop pentestnotes
cd /opt/pentestnotes              # your project dir
cp -r /opt/pentestnotes /opt/pentestnotes-backup-$(date +%F)   # safety copy

# Replace ONLY the code — keep data/, media/, .env, venv/:
#   overwrite the notes/ and config/ folders, manage.py, and requirements.txt
#   from this package. Do NOT touch data/ media/ .env venv/.

source venv/bin/activate
pip install -r requirements.txt        # installs django-axes  (REQUIRED)
python manage.py migrate               # adds axes tables only (REQUIRED; data safe)
python manage.py seed_demo             # adds the default tags (safe to re-run)
python manage.py collectstatic --noinput
sudo systemctl start pentestnotes
```

`migrate` only ADDS django-axes tables; it does not alter your notes/users/files.
`seed_demo` is idempotent — it only fills in missing groups/tags/demo content.

## Create the second admin (safety net for lockout)

Run once on the server (password passed as an argument, never stored in code):

```bash
python manage.py create_user notesAdmin --group Administrator --password 'aewjh()D)WA*HYd(UHG9phG'
```

Having two admins means if one is ever locked out, the other can unlock it from
the Users page.

## Files in this package (full project)
Replace these folders/files from the zip:
- `notes/`  (all app code, templates, static, migrations)
- `config/` (settings, urls)
- `manage.py`
- `requirements.txt`
Leave untouched on the server: `data/`, `media/`, `.env`, `venv/`, `staticfiles/`
(regenerated by collectstatic).
